Why convert a PDF to Word?

A PDF is made to be read, not changed. When you need to fix a typo in a contract, reuse a paragraph from a report, update an old CV or copy text from a form, you want an editable file. A Word document lets you type, delete, reformat and save the changes.

Many converters upload your PDF to a server. This one does not. The text is read and the .docx file is built on your own device, which is better for contracts, ID documents, financial papers and anything private.

How this tool builds your Word file

The tool reads the real text from each page of the PDF and writes it as normal Word paragraphs:

  • It rebuilds lines and paragraphs. Text on the same line is joined, and a new paragraph starts where the PDF has a clear break, a short line or a change in text size.
  • It keeps basic formatting. Bold, italic, font size, indents and page breaks carry over.
  • It matches fonts to common ones. Serif fonts become Times New Roman, monospaced fonts become Courier New, and everything else becomes Calibri.
  • It sets the page size. Keep Match the PDF, or choose A4 or US Letter. The Word page has 1 inch (2.54 cm) margins.
  • It handles scans for you. A page with no text can be inserted as an image or skipped, depending on your choice.

What this tool cannot do

  • No OCR. Scanned pages are pictures, so their words cannot become editable text. They can only be placed in the Word file as images.
  • Layout is simplified. Complex tables, multiple columns and exact positioning may not come out as they were. Expect some touch-ups in Word.
  • Pictures on text pages are not copied. The tool carries over text. Logos and photos on a page that has text may be missing from the Word file, so check for them.
  • Password-protected PDFs. Remove the password in your PDF viewer first.

Tips for better results

  • Check the first page. Open the .docx and compare it with the PDF before you edit a long document.
  • Start from a text-based PDF. A PDF saved from Word or another program converts much better than a phone scan.
  • Convert only what you need. Use Split PDF to pull out the pages you want to edit.
  • Need a table in a spreadsheet? PDF to Excel is built for tables. For plain text, PDF to Text is quicker.
  • Done editing? Turn the document back into a PDF with Word to PDF, and use Compress PDF if the file is too big to send.
  • Only small changes? The Edit PDF tool can add text and drawings straight onto the PDF.

Frequently asked questions

Quick answers about the ConvertKit Lite PDF to Word tool.

Are my documents uploaded to a server?

No. The Word file is created in your browser, so your files stay on your device.

Is the text in the Word file editable?

Yes. The tool reads the real text from your PDF and writes it as normal Word paragraphs you can edit.

What formatting is kept?

Bold, italic, font size, paragraph breaks, indents and page breaks. Fonts are matched to Calibri, Times New Roman or Courier New.

What about scanned PDFs?

Scanned pages contain pictures, not text, so they cannot be edited. By default they are inserted as images; you can also skip them. OCR is not included.

Does it support password-protected PDFs?

No. Remove the password first, then convert the file.

Can I convert many files at once?

Yes. Add several PDFs, convert them together, and download each .docx or one ZIP.

Will the Word file look exactly like my PDF?

Not always. Text, bold, italic, sizes and paragraphs are kept, but the layout is rebuilt as normal Word paragraphs. Complex tables, columns and exact positioning may need touch-ups in Word.

Are images and logos kept?

The tool converts text. Pictures on pages that have text are not copied into the Word file. Pages with no text can be inserted as images if you choose that option.

What does Insert page as image do?

For a page with no selectable text, the tool draws the page as a picture and places it in the Word file at the size of that page. You can see the picture but not edit its words. Choose Skip them if you do not want those pages.

Can I choose the page size?

Yes. Match the PDF uses the size of your first page. You can also pick A4 or US Letter. The margins are 1 inch (2.54 cm).

What file will I get?

A .docx file with the same name as your PDF. It opens in Microsoft Word and in other programs that read the .docx format.

Why does it say no text was found?

The PDF is probably scanned, so its pages are pictures. Set the scan option to Insert page as image, or run OCR on the file first.

Does it work on a phone?

Yes, in any modern browser on Android, iPhone, Windows and Mac. Long PDFs can take longer on older phones, and the result is easier to check on a larger screen.

Is there a watermark or a limit?

No watermark, no account and no limit on how many files you convert.

How many PDFs can I convert at once?

The tool sets no limit. Large batches use your device memory, so convert in smaller groups if your browser slows down.

Can I download all the Word files together?

Yes. After conversion, press Download all (ZIP) to get every .docx in one file.
