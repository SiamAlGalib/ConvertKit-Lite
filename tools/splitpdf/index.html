Frequently asked questions

Quick answers about splitting PDFs with ConvertKit Lite.

Is it safe to split my PDF here?

Yes. Splitting runs in your browser, so your file is not uploaded to a server.

How do I extract specific pages?

Pick "Extract page range" and type pages like "2, 4-6". Each row you add becomes its own PDF.

Can I split every page into a separate file?

Yes. Choose "Split every page" and you will get a ZIP containing one PDF per page.

Does it work with password-protected PDFs?

Many files with only edit restrictions work fine. PDFs that need a password to open can't be read, so remove the password first.

Is there a file size limit?

There is no limit on our side. Very large files depend on your device's memory, so they may take longer.
