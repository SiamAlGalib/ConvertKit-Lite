What happens with a scanned PDF

A scanned PDF is a set of pictures of pages, with no real text inside. This tool does not do text recognition (OCR), so it cannot turn a scan into editable text.

  • Use Image slides: each scanned page becomes one slide picture, in the original order.
  • Avoid Editable text: it needs real text, so scanned pages come out as empty slides.
  • Need to edit the words? Run the scan through an OCR program first, then convert the result.
  • Sharper scans: choose High or Maximum quality.

Why convert a PDF to PowerPoint?

A PDF is made to be read, not presented. Turning its pages into slides lets you show a report, a handout or a set of charts in a meeting, add speaker notes in PowerPoint, mix the pages with other slides, or reuse some of the text in a new deck.

This tool builds the PPTX file inside your browser. Your PDF is not uploaded to a server, so private documents stay on your device.

How this tool builds your slides

  • One page becomes one slide. The slides follow the order of the PDF pages.
  • The slide shape comes from your first page. A landscape first page gives wide slides and a portrait first page gives tall slides. Every page is scaled to fit and centred on its slide.
  • Image slides mode draws each page as a picture, so fonts, images and layout look identical to the PDF. The text is part of the picture, so you cannot edit it in PowerPoint.
  • Editable text mode reads the text from each page and places it on the slide as separate text boxes. You can edit the words, but pictures, shapes, tables and complex layouts are not copied.
  • Quality applies to image slides. Standard, High and Maximum draw the page larger before it is saved as a picture. Maximum gives the sharpest slides and the biggest file. The quality menu is switched off in text mode.
  • The file is named after your PDF. report.pdf becomes report.pptx.

Limits to know

  • Editable text is basic. Text is rebuilt in Arial and in black. Bold fonts are kept as bold, but other font names, sizes, colours and the exact position of every line can differ from the PDF.
  • Text arrives in small pieces. Each piece of text found on the page becomes its own text box, so a paragraph may be split into several boxes rather than one.
  • Scanned PDFs have no text to read. A scan is a picture of a page, so use Image slides mode for it. Editable text will give you empty slides.
  • Password-protected PDFs are not opened. Remove the password first and try again.
  • There is no fixed page limit. Very large PDFs depend on your device's memory. Choose Standard quality if a big file is slow.
  • An internet connection is needed once. The PDF reader and PowerPoint libraries are loaded from a content delivery network when the page opens.

Tips for better results

  • Keep the look? Use Image slides. It is the safest choice for designed documents, charts and anything with pictures.
  • Need to edit the words? Use Editable text. It works best on simple, text-based pages, and you can fix fonts and positions in PowerPoint afterwards.
  • Only want some pages? Cut the PDF down first with Split PDF, so you do not have to delete slides later.
  • Slides too heavy to send? Pick Standard quality, or shrink the PDF first with Compress PDF.
  • Want a Word file instead? Try PDF to Word, or PDF to JPG if you only need pictures of the pages.
  • Going the other way? PPTX to PDF turns a presentation back into a PDF.

Frequently asked questions

Quick answers about the ConvertKit Lite PDF to PowerPoint tool.

Is my PDF uploaded to a server?

No. The conversion runs entirely in your browser, so your file stays on your device.

What is the difference between the two modes?

Image slides place each page as a picture, so the look matches the PDF exactly but text can't be edited. Editable text rebuilds the words as text boxes you can change, but complex layouts, images and graphics are not kept.

Can I convert a scanned PDF to editable text?

Not in this version. Scanned PDFs contain pictures of text, so use image slides mode for them.

Is there a page or size limit?

There is no fixed limit, but very large PDFs depend on your device's memory. Choose Standard quality if a big file is slow.

Why are my fonts different in editable mode?

PDF fonts are often embedded and can't be copied into PowerPoint, so text uses Arial. Change the font in PowerPoint if you need to.

Which mode should I choose?

Choose Image slides when the document must look exactly like the PDF. Choose Editable text when you mainly want to change the words and the layout is simple.

Will my fonts and colours be kept?

In Image slides mode, yes, because each page is a picture. In Editable text mode the text is rebuilt in Arial and in black, with bold kept where the PDF font name shows it, so change the fonts and colours in PowerPoint if you need to.

How big will my slides be?

The slide takes the shape of the first page in your PDF. Every page is then scaled to fit its slide and centred, so no page is cropped.

What does the image quality setting do?

It decides how large each page is drawn before it is turned into a picture. Standard is lighter, High is the default, and Maximum is the sharpest but makes a larger file. It only applies to Image slides mode.

Why are my text boxes split into small pieces?

The tool places each piece of text it finds on the page as its own box. A line or paragraph can therefore be made of several boxes. If you want to rewrite a block, select the pieces and edit them together in PowerPoint.

Why are my pictures and tables missing in editable mode?

Editable text mode copies only the text. Images, shapes, tables and graphics are not carried over. Use Image slides mode if you need them to appear.

Why did I get empty slides from a scanned PDF?

A scanned PDF holds pictures of pages with no real text, so there is nothing to turn into text boxes. Use Image slides mode for scans.

Can I convert a password-protected PDF?

Not directly. You will see a message asking you to remove the password first and try again.

Can I download the PowerPoint again?

Yes. When the conversion finishes, press Download again in the result box to save the same file once more.

What if I get an error?

A conversion error usually means the PDF is damaged or too large for your device. The converter also needs its libraries to load, so turn off ad blockers for this site, check your connection and reload. Try Standard quality for large files.

Does this tool recognise text in scanned PDFs (OCR)?

No. It does not do OCR, so a scan cannot become editable text. It can place each scanned page on a slide as a picture.

How can I tell if my PDF is a scan?

Try selecting text in the PDF. If you cannot select any words, the pages are pictures and need Image slides mode.
