Frequently asked questions

Quick answers about the ConvertKit Lite CSV to XLSX tool.

Are my files uploaded to a server?

No. The XLSX file is created in your browser, so your CSV files stay on your device.

How is the delimiter detected?

The tool checks the first lines of the file for commas, semicolons, tabs and pipes, and picks the one that appears consistently on every line. If it guesses wrong, choose the delimiter yourself from the list.

Why did my ZIP codes or IDs keep their leading zeros?

Values such as 00123 and numbers longer than 15 digits are kept as text on purpose. Excel would otherwise remove the zeros or round the number. Choose "Keep everything as text" if you want every cell left exactly as written.

Does it support Bengali, Arabic, Hindi or Chinese text?

Yes. XLSX files store Unicode text, so every language is kept as real, selectable text. The tool reads UTF-8, UTF-16 and Windows-1252 CSV files automatically.

Are dates converted?

Dates are left as text exactly as they appear in the CSV, so day/month order is never guessed wrongly. You can format them as dates in Excel afterwards.

Are there size limits?

Each file can be up to 20 MB. An Excel sheet holds at most 1,048,576 rows and 16,384 columns, and a single cell holds up to 32,767 characters. Longer cells are shortened.

Can I convert many files at once?

Yes. Add several CSV files, convert them together, and download each XLSX file or one ZIP.
