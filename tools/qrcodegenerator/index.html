Frequently asked questions

Quick answers about the ConvertKit Lite QR Code Generator.

Is my data uploaded anywhere?

No. The QR code is generated in your browser, so your links, text and Wi-Fi password are not sent to a server.

Does the QR code expire?

No. The code simply contains your text, so it works as long as the link or information inside it stays valid.

Which error correction level should I use?

Medium suits most uses. Choose a higher level if the code may get dirty or damaged, but it makes the code denser. Lower levels give simpler codes.

PNG or SVG?

PNG works everywhere. SVG stays sharp at any size, which is best for printing or resizing.

Why does it say there is too much data?

A QR code can only hold a limited amount of text. Shorten the text or choose a lower error correction level.

Will my colors scan properly?

Use a dark color on a light background with strong contrast. Light-on-dark or low-contrast combinations may not scan on every device.
