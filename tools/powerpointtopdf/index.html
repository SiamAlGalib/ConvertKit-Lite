Frequently asked questions

Quick answers about the ConvertKit Lite PowerPoint to PDF tool.

Are my files uploaded to a server?

No. The PDF is created in your browser, so your presentations stay on your device.

Will the PDF look exactly like my slides in PowerPoint?

For most presentations it will be very close. Text, pictures, shapes, tables, backgrounds, bullets and numbering are all drawn. Some things are not supported: charts, SmartArt, videos, animations and transitions. If a slide contains objects that could not be drawn, the file list tells you how many were left out. For a pixel-perfect result on a complex deck, use File > Export > PDF inside PowerPoint.

Why do some fonts look different?

The conversion happens in your browser, which can only use fonts installed on your device. If your presentation uses a font you do not have, a similar font is used instead, so line breaks can shift slightly.

Can I select and search the text in the PDF?

Yes for Latin-script text. Each slide is drawn as a high-quality image so it looks the same everywhere, and the text is added on top as an invisible layer so you can search and copy it. Text in other scripts, such as Bengali, Arabic or Chinese, looks correct but is not searchable.

Does it work with old .ppt files?

No. Only the modern .pptx format (plus .pptm, .ppsx and .potx) is supported. To convert an old .ppt file, open it in PowerPoint, choose Save As and pick PowerPoint Presentation (.pptx), then add it here.

How do I get a smaller PDF?

Choose Standard quality. High and Maximum draw slides at a higher resolution, which looks sharper when zoomed or printed but makes the file larger.

Can I convert many files at once?

Yes. Add several presentations, convert them together, and download each PDF or one ZIP.
