Why extract archives online?

ZIP and RAR files turn up everywhere: school work, project files, photo bundles and downloads. Phones, Chromebooks and locked-down work computers often cannot open RAR files at all, and installing software is not always possible. Opening the archive in a browser fixes that.

This extractor works on your own device. Your archive is opened in the browser's memory and is not uploaded, so private documents stay private.

How this tool works

  • It checks the real file type. Whether the file ends in .zip or .rar, the tool reads the start of the file to see what it really is, and tells you if it is neither.
  • You see what is inside first. After extracting, every file is listed with an icon and its size, and each one has its own Download button.
  • Folders are your choice. Keep folders to preserve the original structure, or pick Flat list to see every file by its own name. If two files share a name in a flat list, the second gets a number, such as photo-2.jpg.
  • System clutter can be skipped. By default, __MACOSX folders, .DS_Store and Thumbs.db files are left out. They are added by Mac and Windows and are rarely wanted.
  • Download everything at once. The ZIP download packs the extracted files again. With several archives, each goes into its own folder named after the archive.

Limits to know

  • ZIP and RAR only. This includes RAR5. Formats such as 7z, TAR and GZ are not supported.
  • Password-protected ZIP files are not supported. Password-protected RAR files are: type the password in the box before you press Extract.
  • Split RAR archives cannot be opened. Files such as part1.rar and part2.rar need a single-file archive.
  • About 1.5 GB of extracted data. Because everything is held in your device's memory, archives that expand to more than this are refused. Use a desktop tool for very big archives.
  • Only the first 300 files are listed per archive. The rest are mentioned below the list and are still included in the ZIP download.
  • RAR needs a one-time download. The RAR component is loaded only when you open a RAR file, so you need an internet connection for it. ZIP files use a component that loads with the page.

Tips for better results

  • Wrong password? The file will show "Wrong password." Check upper and lower case and try again.
  • Got a pile of photos? Shrink them with Image Compressor & Resizer or bundle them into one file with JPG to PDF.
  • Extracted a set of PDFs? Join them with Merge PDF, cut pages out with Split PDF, or shrink them with Compress PDF.
  • Need a safer download? Check the file names in the list before you save anything, and only open files from sources you trust.

Frequently asked questions

Quick answers about the ConvertKit Lite ZIP / RAR Extractor.

Are my files uploaded to a server?

No. Archives are opened in your browser, so your files stay on your device.

Which formats are supported?

ZIP and RAR (including RAR5). Other formats such as 7z, TAR and GZ are not supported yet.

Can I open password-protected archives?

Password-protected RAR files work: enter the password in the password box before extracting. Password-protected ZIP files are not supported in the browser. Use a desktop tool such as 7-Zip for those.

Does it support multi-part RAR archives?

No. Split archives (part1.rar, part2.rar and so on) cannot be opened here. Use a single-file archive.

Why does a large archive fail?

Everything is extracted in your device's memory, so archives that expand to more than about 1.5 GB are rejected to avoid crashing the browser. Try a desktop tool for very large files.

What does Flat list do?

It ignores folder names and lists every file by its own name. If two files share a name, the second one gets a number added, such as photo-2.jpg.

What happens if the archive is empty?

The tool shows the archive with a message that no files were found. Empty folders are not kept, only files.

Does it keep the folder structure?

Yes, by default. Files are listed with their folder path, and the ZIP download keeps the same folders. Choose Flat list to ignore folders.

Can I change the folder option after extracting?

Yes. Switching between Keep folders and Flat list updates the file list and the ZIP download straight away, without extracting again.

Which files are treated as system files?

Anything inside a __MACOSX folder, plus .DS_Store and Thumbs.db. Choose Include everything if you want them anyway.

Is it safe to open archives here?

Extracting only unpacks the files into your browser's memory. Nothing is run, but a file you download can still be harmful when you open it, so only keep files from people and sites you trust.

Does it work on a phone?

Yes, in a modern browser. Extracting is done in memory, so big archives are better on a computer.

What is in the ZIP I download?

The extracted files, stored without extra compression. With one archive it is named after the archive plus -extracted.zip. With several archives it is called extracted-files.zip, with a folder for each.

Is there a limit on how often I can use it?

No. There is no account, no watermark and no limit on how many archives you open.

How do I extract a ZIP without the folders?

Choose Flat list under Folder structure. Every file is listed and saved by its own name, and folders are ignored.

What happens when two files have the same name in a flat list?

The second one gets a number added, for example photo-2.jpg, so nothing is overwritten.
