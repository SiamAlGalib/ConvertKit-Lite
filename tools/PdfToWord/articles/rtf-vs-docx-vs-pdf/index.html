What Is a DOCX File?

Updated October 4, 2026 · 3 min read · By ConvertKit Lite

A DOCX file is a document saved in the Office Open XML format, the default for Microsoft Word since Word 2007. It stores text, formatting, images and layout settings in a single file.

What Is Inside a DOCX File?

A DOCX is a compressed ZIP package of XML files and media. One part holds the document text, another holds styles, and pictures sit in a media folder. This structure keeps files small and lets many apps read them.

How to Open a DOCX File

  • Microsoft Word on desktop, web and mobile.
  • Google Docs by uploading the file to Google Drive.
  • LibreOffice Writer, a free desktop option.
  • Apple Pages on Mac, iPhone and iPad.

DOCX vs DOC

DOC is the older Word format used before 2007. DOCX files are usually smaller, more reliable and better supported by modern apps, so use DOCX unless someone specifically needs the old format.

DOCX vs PDF: When to Use Each

Use DOCX while a document still needs editing. Use PDF when you want it to look the same on every device, for final sharing or printing. See our full RTF vs DOCX vs PDF comparison.

Is a DOCX File Safe?

A standard .docx file cannot contain macros, since macro-enabled Word files use the .docm extension. Even so, only open documents from sources you trust. To make one yourself, see how to convert PDF to Word.

Key Features of the DOCX Format

  • Styles and formatting: headings, fonts, colors and spacing.
  • Tables and images: built-in support for layouts, pictures and charts.
  • Review tools: comments and tracked changes for teamwork.
  • Headers, footers and page numbers for longer documents.
  • Compact size: ZIP compression keeps files small.

DOCX vs DOCM vs DOTX

Word uses different extensions for related file types:

ExtensionWhat it isContains macros
.docxStandard Word documentNo
.docmWord document with macros enabledYes
.dotxWord template for new documentsNo

Why Won't My DOCX File Open?

  • No compatible app: install Word or LibreOffice, or open the file in Google Docs.
  • Incomplete download: download the file again.
  • Wrong extension: check that the file really ends in .docx.
  • Damaged file: in Word, use File › Open › Open and Repair.

How to Convert DOCX to PDF

To share a document that looks the same on every device, save or export it as PDF. In Word choose File › Save As › PDF, or use our Word to PDF converter.

When Should You Use a DOCX File?

Choose DOCX for drafts, resumes you still update, reports with several authors and anything that needs comments or tracked changes. Switch to PDF once the content is final.

Frequently Asked Questions

What does DOCX stand for?

The name combines DOC with an X for XML, the format the file is built on.

Can I open a DOCX file without Microsoft Word?

Yes. Google Docs, LibreOffice Writer and Apple Pages all open DOCX files.

Is DOCX the same as DOC?

No. DOC is the older binary format. DOCX is the newer XML-based format and is usually smaller and more reliable.

Can a DOCX file contain a virus?

A .docx file cannot carry macros, but any file can contain risky links or be disguised, so only open documents from sources you trust.

How do I turn a PDF into a DOCX file?

Use the converter at the top of this page: add your PDF, press Convert to Word and download the .docx.

Which is better for editing, DOCX or PDF?

DOCX. PDF is meant for final sharing, so editing it directly is limited.
