What you'll learn in this guide

How to convert WebP to JPG, how to convert many files at once, what happens to transparent backgrounds, how to keep quality high and file size low, and how to fix the most common problems.

Why Convert WebP to JPG?

WebP is a modern image format that websites like because the files are small. The problem is that not everything opens it. JPG works almost everywhere, which is why people convert WebP to JPG when they need to:

  • Upload a photo to an online form or job application that only accepts JPG.
  • Open an image in an older app or email program.
  • Send a file to a print shop.
  • Add images to PowerPoint, Word or a PDF.
  • Share pictures on WhatsApp, Discord, Facebook or Instagram.

How to Convert WebP to JPG

  1. Open the WebP to JPG converter.
  2. Click the upload area, or drag and drop your .webp files onto it.
  3. Set the JPG quality. The default is 90%.
  4. Choose the color for transparent areas: white, black or gray.
  5. Select Convert to JPG.
  6. Download each JPG, or press Download all (ZIP).

Is My Image Uploaded? Is It Private?

No upload is needed. The conversion happens in your browser, so your images stay on your device. There is no account to create and no limit on how often you use it. That makes it a good choice for personal photos and documents you would rather not send to a server.

Can I Convert WebP to JPG Without Losing Quality?

JPG is a lossy format, so a tiny amount of detail is always lost when an image is saved as JPG. At 90% quality the difference is very hard to see, and at 100% you get the best result the format can give. A few tips:

  • Use 90% for a good balance of sharpness and file size, and 100% when quality matters most.
  • Convert from the original WebP once. Saving a JPG again and again lowers quality each time.
  • Keep your original WebP file as a backup.
  • Need zero loss? A lossless format like PNG is the better choice. See WebP vs JPG vs PNG for the differences.

How to Convert Many WebP Files at Once

You don't have to convert images one by one. Add several WebP files, convert them together and download all the JPGs in a single ZIP. This is handy for product photos or a batch of images you saved from a website.

To add a whole folder of images, open the file picker, press Ctrl+A (Cmd+A on a Mac) to select every file in the folder, then confirm. Dragging files onto the upload area works too.

What Happens to Transparent Backgrounds?

JPG can't store transparency, so transparent areas must be filled with a solid color. The converter lets you pick white, black or gray.

  • White suits documents, forms and most product photos.
  • Black or gray is better for white or very light logos that would disappear on white.
  • If you need to keep the transparency, don't use JPG. Keep the image as PNG instead.

The converter doesn't offer a custom background color. If you need a brand color, convert first and then edit the JPG in an image editor.

What About Animated WebP Files?

JPG doesn't support animation, so only the first frame of an animated WebP is converted. If you need to keep the movement, a video or GIF format is a better fit.

How to Make the JPG Smaller (Under 100 KB, 200 KB or 1 MB)

Many forms and websites set a maximum file size. The converter has no "target size" button, but you can get there in a few steps:

  1. Convert the image and check the file size.
  2. If it is too big, convert again with a lower quality, for example 80%, then 70%.
  3. Still too large? Resize the image with the Image Compressor & Resizer. Fewer pixels means a smaller file.

Using Your JPG on Websites, Apps and Forms

  • Online forms, job applications and ID or passport photos: JPG is widely accepted, but each portal has its own rules for size and dimensions. Converting changes the format only, so check the official requirements.
  • WordPress, Shopify, WooCommerce, Amazon and eBay: JPG is a safe choice for product and listing images. Check each platform's image guidelines for size and dimensions.
  • Facebook, Instagram, WhatsApp and Discord: JPG works everywhere, so it avoids "unsupported format" errors.
  • Gmail, PowerPoint and Word: JPG can be attached and inserted without problems.
  • Printing: Print quality depends on the pixel size of the original image. A format change can't add resolution, and the converter has no DPI setting.

Convert WebP to JPG on Any Device

Because the converter runs in your browser, there is no app to install. Open it in Chrome, Safari, Edge or Firefox on Windows 10, Windows 11, Mac, Linux, Android (including Samsung phones), iPhone or iPad. Tap or click the upload area, choose your WebP files and convert.

Why Do Images Download as WebP?

Many websites serve their pictures in WebP, so when you right-click and save an image in Chrome, you get a .webp file. There is no simple built-in switch in Chrome to save it as JPG, so the easiest fix is to convert the file after you download it.

Can I Just Rename .webp to .jpg?

It's tempting, but renaming only changes the name, not the data inside. The file is still a WebP. Some apps will open it anyway, but many will show an error or refuse it. Converting properly is the safe way to get a real JPG.

For Developers: Script It Instead

ConvertKit Lite is a browser tool, not an API or plugin. If you need to automate conversions in your own scripts, here are two simple options.

Python with the Pillow library:

from PIL import Image

img = Image.open("photo.webp").convert("RGB")
img.save("photo.jpg", quality=90)

ImageMagick 7 on the command line (Windows PowerShell, Mac Terminal or Linux):

magick photo.webp photo.jpg
magick mogrify -format jpg *.webp

The second line converts every WebP in the current folder. Note that images with transparency may get a black background with these commands, so fill the background with white first if that matters.

Fix Common Problems

  • The JPG looks blurry. Raise the quality to 95% or 100%. If the original is small, no converter can add sharpness that isn't in the image.
  • The colors look different. Apps and screens can display colors slightly differently. Open both files in the same viewer before assuming something went wrong.
  • There is a black background. A transparent area was filled with black. Convert again and choose white.
  • Nothing happens or the conversion fails. Make sure the file really is a .webp, try fewer files at once, and update or switch your browser.
  • An app says "WebP not supported." Convert the image to JPG and use the new file.
  • You need the photo's metadata. The converter has no option to keep EXIF data, so keep the original file if you need it.

Common Mistakes to Avoid

  • Renaming instead of converting. A renamed file is still a WebP.
  • Expecting transparency to stay. JPG always fills it with a solid color.
  • Using 100% quality when size matters. Lower the quality if you have a file size limit.
  • Converting the same image over and over. Always start from the original.
