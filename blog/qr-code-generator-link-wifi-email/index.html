What you'll learn in this guide

How to make a QR code for a link, Wi-Fi or email, what error correction means, whether to download PNG or SVG, and how to make sure your code scans.

What Can You Put in a QR Code?

The generator has three types:

  • Link / Text: a web address or any short text, such as a message or a phone number.
  • Wi-Fi: your network name, password and security type, so guests can join by scanning instead of typing.
  • Email: an address, plus an optional subject and message, so scanning opens a ready-to-send email.

How to Make a QR Code

  1. Open the QR Code Generator.
  2. Choose a type: Link / Text, Wi-Fi or Email.
  3. Fill in the details. The QR code appears and updates as you type.
  4. Adjust the colors, error correction and size if you want.
  5. Select Download PNG or Download SVG.

How to Share Wi-Fi With a QR Code

Pick the Wi-Fi tab, enter your network name, your password and the security type (WPA is the right choice for most home networks). Download the code and print it or show it on a screen. When a guest scans it with their phone camera, they can join without typing the password.

What Is Error Correction?

Error correction lets a QR code still scan when part of it is dirty, scratched or covered. The tool offers four levels:

  • Low (7%): the simplest code, for clean screens.
  • Medium (15%): a good default for most uses.
  • Quartile (25%): for codes that may get a little worn.
  • High (30%): the most forgiving, but the code gets denser.

If you aren't sure, keep Medium.

PNG or SVG?

PNG is an image that works almost everywhere, such as documents, chats and websites. SVG stays sharp at any size, so it is the better choice for printing, posters and anything you might enlarge later.

Tips to Make Sure Your QR Code Scans

  • Use strong contrast. A dark code on a light background scans best. Light-on-dark or low-contrast colors may not scan on every device.
  • Keep the white border. The empty margin around the code helps scanners find it, so don't crop it.
  • Don't make it too small. When printing, choose a size that is easy to scan from a normal distance.
  • Keep the content short. A QR code holds a limited amount of text. If you see a "too much data" message, shorten the text or lower the error correction level.
  • Test it. Scan the code with your phone before you print many copies.

Does a QR Code Expire?

No. The code simply contains your text, so it works for as long as the link or information inside it stays valid. If you link to a web page that is later removed, the code will lead nowhere.

Is It Private?

Yes. The QR code is generated in your browser, so your links, text and Wi-Fi password are not sent to a server. Keep in mind that anyone who scans a Wi-Fi code can read the password inside it, so only share it with people you trust.
